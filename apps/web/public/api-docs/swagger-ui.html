🏎️ ChronoF1 API Documentation

F1 라이브 타이밍 및 히스토리 데이터 API

📋 API 개요

ChronoF1은 Formula 1의 역사적 결과 데이터와 2018년 이후 라이브 타이밍 리플레이를 제공하는 NestJS 기반 API입니다.

🚀 WebSocket 라이브 타이밍 가이드 보기

🏁 라이브 타이밍

F1 세션의 실시간 타이밍 데이터를 WebSocket을 통해 제공합니다. 청크 기반 시스템으로 효율적인 데이터 전송을 지원합니다.

📊 히스토리 데이터

시즌별 이벤트, 세션, 드라이버 정보 등 F1 역사 데이터를 REST API로 제공합니다.

🔧 기술 스택

NestJS, TypeScript, Prisma ORM, PostgreSQL + TimescaleDB, Redis, Socket.IO

📡 데이터 소스

FastF1 라이브러리를 사용하여 공식 F1 텔레메트리 데이터를 수집하고 가공합니다.

🌐 개발 환경

  • API 서버: http://localhost:3000
  • WebSocket: ws://localhost:3000/live-timing
  • Swagger UI: http://localhost:3000/api-docs (백엔드 실행 시)

📝 사용 가이드

  1. 아래 API 문서에서 원하는 엔드포인트를 찾아보세요
  2. WebSocket 라이브 타이밍을 사용하려면 "라이브 타이밍" 섹션을 확인하세요
  3. 모든 응답은 { success: boolean, data?: any, error?: string } 형태입니다
  4. 인증이 필요한 API는 JWT 토큰을 사용합니다
